## ✨ Features

- **Responsive Layout:** Designed to display cleanly across mobile phones, tablets, and desktop screens.
- **Gradient Navigation Header:** A sticky navigation bar that stays accessible as you scroll through the page.
- **Dark / Light Mode Toggle:** An interactive theme switcher that saves user preference across refreshes using `localStorage`.
- **Smooth Page Scrolling:** Glides seamlessly to different sections when clicking navigation links.
- **Dynamic "Back to Top" Button:** Appears automatically once scrolled past 300px for easy navigation.
- **Interactive Project Cards:** Hover lift effects showcasing project descriptions, tech stack tags, and repository links.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, and media queries for responsiveness.
- **JavaScript (Vanilla ES6):** DOM manipulation, event handling, and theme state persistence.
- **Google Fonts:** Clean typography powered by the `Poppins` font family.
